# Interactive Personal Data Collector

A beginner-friendly Python program that collects personal information from the user and displays it along with data types, memory addresses, and an approximate birth year.

## Features

* Collects user information:

  * Name
  * Age
  * Height
  * Favourite Number
* Displays:

  * User-entered data
  * Data types using `type()`
  * Memory addresses using `id()`
* Calculates approximate birth year based on age.
* Demonstrates basic Python concepts such as:

  * Variables
  * User input
  * Type conversion
  * Arithmetic operations
  * Output formatting

## Requirements

* Python 3.x

## How to Run

1. Save the program as `personal_data_collector.py`
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python personal_data_collector.py
```
